# 메뉴 구성 맞히기

`index.html`을 브라우저에서 열면 실행됩니다.

- 메뉴 이름이 무작위로 표시됩니다.
- 후보 항목을 눌러 선택하고 제출합니다.
- 구성 항목의 **순서는 무시**하며, 빠진 항목이나 불필요한 항목 없이 정확히 일치해야 정답입니다.
- 설정에서 구성 항목과 메뉴를 추가·수정·삭제할 수 있습니다. 메뉴 구성은 쉼표(`,`)로 구분해 입력하세요.
- 변경 사항은 브라우저에 저장되며, JSON 내보내기/가져오기를 지원합니다.

초기 메뉴와 구성 데이터는 `menu.xlsx`의 색칠된 첫 번째 열과 오른쪽 구성 열을 바탕으로 가져왔습니다.
